📡 DNS Optimizer

Switch to Cloudflare DNS for faster gaming connections

Android: Settings → WiFi → Long press network → Modify → Advanced → DNS → Manual → Set to 1.1.1.1
PC (Windows): Settings → Network → Change adapter options → Properties → IPv4 → Use DNS: 1.1.1.1 and 1.0.0.1
Why it works: Cloudflare DNS is the world's fastest DNS — reduces lag on game servers 🚀
